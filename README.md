## About

I'm an Electronics & Communication Engineer interested in building systems across **digital design, VLSI/RTL, embedded systems and PCB hardware**.

I enjoy working from the lowest-level logic — FSMs, RTL and FPGA design — up through firmware, boards and complete embedded prototypes.

```text
Focus:   VLSI / RTL Design · Embedded Systems · PCB Design · Digital Hardware
Build:   Verilog · C/C++ · Python · STM32 · FPGA/SoC · KiCad
Explore: Digital Design · Computer Architecture · Hardware Systems
```

- Verilog RTL design
- Finite State Machines
- UART / serial interfaces
